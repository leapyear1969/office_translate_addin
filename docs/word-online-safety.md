# Word Online 翻译限制

段落底纹（`w:pPr/w:shd`，包括背景色）属于支持的基本格式，翻译时原样保留。此前白名单遗漏该属性，会将带底纹的普通文字误报为“文档包含尚未支持的结构或格式”。已增加底纹放行、译文回填保留及未知属性仍被拦截的回归测试。

网页版全文翻译检查整份正文及各类页眉、页脚；放行文字、基本格式、普通矩形表格（包括空单元格）和 DrawingML 普通图片（嵌入型及浮动型）。正文全文翻译包含正文表格文字，页眉和页脚仅检查并保留，不参与翻译。桌面端翻译流程不受此限制，恢复原文入口不受此限制。

2026-09-09：选区、当前段落及右键翻译改为面板预览，不再检查整份文档或自动写回。原文可编辑，译文只读；输入停止 600 毫秒后自动重译，中文输入法组词期间不发送请求，过期响应不更新译文。修改目标语言也会重译。“插入”以纯文本替换最初捕获的范围，保留范围外内容，可使用 Word 撤销；插入不创建全文副本或恢复备份，可能改变范围内混合格式。若范围文字已更改则拒绝写入。手动输入但未捕获 Word 范围时可预览，不能插入。

当前阈值集中在 `src/word/web-safety.ts`：20000 个文字字符（按 JavaScript UTF-16 长度）、500 个正文段落、单次 OOXML 导出 5000000 UTF-8 字节。它们是首版产品限制，不是微软 API 限制。图片资源保留在 OOXML 中，不发送到翻译服务；图片内部文字不翻译。图片仍计入 OOXML 大小限制。旧式 VML 图片、文本框、图表和 SmartArt 尚不放行。允许自动编号、项目符号和多级列表；翻译仅修改文字，保留编号引用、层级及编号定义（含连续编号和重新起始设置）。手工输入的列表符号属于普通文字。

空白页眉/页脚部件、空批注容器以及默认脚注/尾注分隔符不会仅因部件存在而触发拦截。页眉/页脚引用只有在分别检查各类页眉和页脚后才放行。普通页眉/页脚内容和空表格可以保留；仅判断文本为空是不够的，仍检查是否存在合并、嵌套及不支持的绘图等结构。

表格分两步检查：先加载正文和六类页眉/页脚的 `tables.items/isUniform`、`nestingLevel`，行列不一致或嵌套级别大于 1 即拒绝；通过后仍扫描 OOXML。检查嵌套 `w:tbl`、`w:gridSpan`（仅允许 1）、`w:vMerge`、`w:hMerge`、省略单元格的 `gridBefore/gridAfter`、各行单元格数与 `tblGrid` 列数。`isUniform=true` 不代表没有合并。属性读取失败时停止翻译，不将失败当作 SAFE。

已用用户提供的 TEST ENG.docx 做本地结构验证：正文为 Hello Jason，六个页眉/页脚包含空三列表格；检查通过，生成译文 OOXML 后六个表格保持不变。对该样例注入合并与嵌套结构后均被拒绝。原文档未修改，未加入仓库。

检查在读取待翻译内容前、翻译服务返回后、原文备份保存后执行。无法导出或解析结构时停止，不降级为 HTML 检查。未知内容或格式默认拒绝。Office 检查和写入不是原子事务，这些检查不能保证同时协作编辑时绝无变化。

网页版全文翻译在安全检查通过后，先将原生原文备份保存到当前浏览器，再替换当前文档；备份失败则停止。桌面端全文翻译每次创建完整 DOCX 新副本，在副本中翻译并保存恢复备份，最后打开副本供用户保存。

Word Online 全文翻译使用原生 OOXML，失败时不回退为 HTML。图文同段时以图片为界分别翻译两侧文字，只改文字节点，保留图片引用、尺寸、锚点和包内资源。写入前重新读取范围并校验文字及分段映射，将译文回填到最新结构。

## 实机验收（尚待执行）

以下结构和备份验收项适用于全文翻译。旧版选区/段落直接回填的验收方式由面板预览验收替代：在 Word Online、Windows Word、Mac Word 分别验证选区和首段捕获、中文输入法、快速修改、切换语言、只读译文、插入后撤销、移动光标后仍插入原范围、原范围被修改后拒绝插入，以及注销时忽略未完成译文。浏览器布局已在 340px 宽度验证，无横向溢出；实际 Office 宿主仍需验收。

- 自动编号、项目符号、多级列表及重新从 1 开始的列表：分别执行全文、选区和段落翻译，保存重开后检查编号连续性、层级、缩进和符号，再恢复原文。覆盖正文、表格内列表以及页眉/页脚列表（页眉/页脚仅保留，不翻译）。本地自动化测试已覆盖结构放行、编号定义保留、最新编号设置回填及三个入口的翻译/恢复；实际 Word Online 写入后的显示效果仍需实机验收。

- 插入嵌入型、浮动型图片，覆盖独立图片段落、图文同段、同一 run 中图文、表格及页眉/页脚图片；分别执行全文、选区和段落翻译，保存重开后检查图片、尺寸、位置、关系和文字，再恢复原文。图片前后文字应被翻译，图片内文字保持不变。

- 文件体积：新增原文及译文校验信息只保存到插件来源下的 IndexedDB（`word-translation-backups` / `documents`），文档设置只保存 `wordTranslation.localBackupId.v1` 短 ID，内容控件保留范围标记。原有 2 MB 文档备份预算已移除，仍遵守翻译内容和 OOXML 大小限制；浏览器配额或权限失败时停止操作，不回退到内嵌备份。
- 旧文件：点击“将旧备份移到此浏览器”，或者执行翻译/恢复时自动迁移。先等待 IndexedDB 事务提交，再移除文档内 `wordTranslation.ranges.v2` 与 `wordTranslation.originalBody.v1` 并保存设置。文档设置保存失败则还原内存设置，保留本地副本供后续重试；不删除原文和其他插件设置。旧版整篇备份只迁移留存，不开启不安全的整篇恢复。
- 迁移后保存并重新下载，检查 `word/webextensions/webextension.xml` 不再含原文备份。实际 DOCX 体积需要实机对比，不能根据未压缩 XML 大小承诺相同压缩收益。
- 恢复依赖相同浏览器配置、插件来源及存储分区。换设备、浏览器、插件域名，清除站点数据、隐私模式退出或浏览器回收存储均可能导致备份不可用；桌面 Word 与网页版不保证共享存储。缺失备份时不覆盖对应范围，并提示使用原浏览器。备份不随文件共享，请保留独立原文件副本。
- 恢复后本地历史仍保留以支持 Word 撤销。文件副本继承短 ID 和既有范围标记，同一浏览器内可恢复继承的范围；新增翻译使用随机范围标记并合并保存。相同标记却对应不同原文时拒绝写入。协作编辑与文档设置保存仍不是原子事务。

- 在 Word Online 打开仅含普通段落、标题和加粗的 docx，验证空页眉/页脚的 OOXML 导出能通过检查，三个翻译入口均可使用。
- 插入普通表格和空表格，验证允许翻译；正文表格文字被翻译，行列结构和格式保留，恢复后原文可取回。
- 对表格横向合并、纵向合并、插入嵌套表格，分别验证拒绝；每行合并方式相同的表格也应拒绝。正文、首页、奇偶页页眉/页脚都覆盖。
- 插入公式、超链接、修订、内容控件，分别验证拒绝翻译且正文不变。即使只选择普通段落也应拒绝。
- 页眉/页脚普通文字和普通表格允许保留；普通图片允许保留；合并或嵌套结构拒绝。
- 验证超过任一阈值的文档被拦截；正文结构读取失败时显示桌面客户端指引。
- 翻译等待期间新增复杂结构，验证不写入译文；右键命令与按钮遵循同一限制。
- 验证网页版备份提示可见，桌面 Word 中提示隐藏，原有翻译和恢复流程可用。

空页眉导出若在某个宿主中失败，会保守拒绝网页版翻译，不能以省略检查的方式放行。正文范围导出不等同于完整 docx 文件，需通过上述实机用例验证目标宿主暴露的结构。
